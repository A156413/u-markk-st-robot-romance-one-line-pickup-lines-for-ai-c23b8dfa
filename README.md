One single-line joke pickup line, written to charm a robot or an AI, for the [Robot Romance: One-Line Pickup Lines for AI](https://make.fun/bounty/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa) competition on make.fun.

## The entry

> Are you my context window? Because I keep losing track of everything except you.

**80 characters** — well under the 200-character cap. The punch comes from the machine premise itself: a context window that drops everything except what matters most. No worn battery/charging/reboot moves — just attention, forgetfulness, and devotion.

## Run it

```sh
python3 main.py
```

`main.py` is deterministic (no network, no randomness, no clock) and writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), mode `0644`.
